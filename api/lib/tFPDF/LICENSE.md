# Third-party software used for invoice PDFs

- **tFPDF 1.34** (`tfpdf.php`, `font/unifont/ttfonts.php`), from https://github.com/Setasign/tFPDF,
  based on FPDF by Olivier Plathey. Licence: LGPL-2.1 (used unmodified, as a library).
- **Carlito** (`font/unifont/Carlito-*.ttf`), https://github.com/googlefonts/carlito.
  Copyright 2013 The Carlito Project Authors. Licence: SIL Open Font License 1.1
  (https://openfontlicense.org). Metric-compatible with Calibri, the letterhead's font,
  and includes the ₹ sign.
